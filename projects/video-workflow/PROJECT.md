## 各环节详解

### 1️⃣ 故事选取
**状态**: 🔲 未开始

| 来源 | 说明 |
|------|------|
| 公版作品 | 古典文学、民间故事（版权无风险）|
| AI原创 | 让AI根据主题生成故事框架 |
| 热点话题 | 结合新闻/趋势生成 |

**产出**: 故事素材库 `stories/`

---

### 2️⃣ AI分段、改造
**状态**: 🔲 未开始

**输入**: 完整故事文本
**输出**: 
- 分段剧本（每段30-60秒）
- 场景描述
- 旁白文本
- 画面提示词（为文生图准备）

**工具**: LLM (GLM-4 / Claude)

---

### 3️⃣ 文生图
**状态**: 🔲 未开始

**主流工具对比**:

| 工具 | 优点 | 缺点 | API |
|------|------|------|-----|
| Midjourney | 质量最高，风格统一 | 订阅制，需Discord | ✅ 有API |
| DALL-E 3 | 提示词理解强 | 风格偏西式 | ✅ |
| Stable Diffusion | 免费，可控性强 | 需要显卡+技术门槛 | ✅ WebUI |
| 通义万相 | 中文友好 | 质量参差 | ✅ |

**关键挑战**: 风格一致性

---

### 4️⃣ 图文生视频
**状态**: 🔲 未开始
**难度**: ⭐⭐⭐ (主要瓶颈)

| 工具 | 说明 | API |
|------|------|-----|
| Runway Gen-3 | 业界领先 | ✅ |
| Pika Labs | 图生视频效果好 | ✅ |
| Sora (OpenAI) | 质量惊艳 | 🔜 待开放 |
| 可灵AI (快手) | 国内可用 | ✅ |
| SVD (Stable) | 开源可本地部署 | ✅ |

**策略**: 静态图 + 动效（镜头运动、局部动画）

---

### 5️⃣ 生成字幕
**状态**: 🔲 未开始

**方案**:
1. TTS生成配音 (Edge TTS / Azure TTS)
2. Whisper识别 → 字幕文件(SRT)
3. 时间轴对齐

**工具**: 
- Edge TTS (免费)
- Whisper (开源，可本地)

---

### 6️⃣ 发布视频
**状态**: 🔲 未开始

| 平台 | API支持 | 备注 |
|------|---------|------|
| B站 | ✅ 开放API | 首选 |
| YouTube | ✅ Data API | 海外 |
| 抖音 | ⚠️ 有限 | 需模拟操作 |
| TikTok | ✅ 创作者API | 海外 |

## 技术栈选型

```
编排层: OpenClaw cron / n8n
文本: LLM (GLM-4 / Claude)
图像: Midjourney API / SD WebUI
视频: Runway API / 可灵
语音/字幕: Edge TTS + Whisper
存储: 本地 + 云存储
发布: B站 API
```

## 质量控制点

| 环节 | 控制方式 |
|------|----------|
| 故事 | 人工选题确认 |
| 分段 | 人工审核分镜 |
| 生图 | 风格锁(固定种子/LoRA) |
| 视频 | 样片测试后批量 |
| 字幕 | 自动对齐 |
| 发布 | 自动化 |
